# Assorted Mobs

Every Assorted Mobs creature in one download: the ice pixie, the treasure mob, the parabuzzy and
the Bob-omb, and the sea creatures. This jar has no code of its own; it carries
[Assorted Ice Pixie](../icepixie), [Assorted Treasure Mob](../treasuremob),
[Assorted 8-Bit Mobs](../eightbit) and [Assorted Sea Creatures](../seacreatures) inside it, and the
game loads them as it would if they were installed one by one.

To keep only some of them, swap this mod for the ones you want. Worlds carry over either way, and a
creature's mod installed on its own beside this one is loaded only once.

Worlds made with Assorted Mobs 1.x load in this mod unchanged: its creatures, items and sounds used
to be `assortedmobs:<name>` and are aliased to their new ids, and a player's recipe book and
advancement progress carry over to the moved recipes and advancements.

Requires [Assorted Lib](https://github.com/AssortedMods/AssortedLib).
